## 통합 항목 (3건)

### A. SkillOpt Slow Update + Meta Skill
<integration_note>

**근거**: Microsoft SkillOpt (Yang et al. 2026, arXiv:2605.23904) 의 ablation 에서 가장 큰 영향 영역:
> "without meta skill + slow update": SpreadsheetBench 77.5 → 55.0 (대폭 하락)

v1.3.0 adapter 는 이를 미구현. v1.4.0 에서 추가.

**파일**: `scripts/skillopt_v1_4_extensions.py`

**핵심 클래스**:
- `SlowUpdate`: epoch 간 longitudinal 비교, persistent rejection 탐지, slow improvement trend
- `MetaSkill`: optimizer 자체 메모리 (edit pattern → success rate)
- `extend_skillopt_adapter(adapter)`: v1.3.0 SkillOptAdapter 에 주입

**활성화**: `SkillOptAdapter` 인스턴스에 `extend_skillopt_adapter()` 호출.
</integration_note>

### B. Reflexion 풀스택 Self-Reflection
<integration_note>

**근거**: Shinn et al. 2023 NeurIPS, arXiv:2303.11366 "Reflexion".
v1.2.0 Goal-Driven Mode 의 `_self_reflect()` 가 단순 unmet 전달 → verbal reinforcement 격상.

**파일**: `scripts/reflexion_full_stack.py`

**핵심 클래스**:
- `ReflectionTrace`: episodic memory (Reflexion paper 의 verbal feedback buffer)
- `build_reflection_prompt()`: 구조화된 reflection prompt 생성 (XML 태그)
- `parse_reflection_response()`: LLM 응답에서 `<reflection>` 블록 파싱
- `ReflexionEnhancedSelfReflect`: v1.2.0 GoalDrivenExecutor 의 `_self_reflect` 대체

**활성화**:
```python
from goal_driven_executor import GoalDrivenExecutor
from reflexion_full_stack import ReflexionEnhancedSelfReflect

reflector = ReflexionEnhancedSelfReflect(llm_callback=my_llm_call)
executor = GoalDrivenExecutor(criteria, worker_runner=my_worker)
executor._self_reflect = reflector.reflect
```

LLM callback 미제공 시 v1.2.0 fallback 동작 (회귀 0).
</integration_note>

### C. Senior Engineer Test 객관 Metric
<integration_note>

**근거**: Karpathy "200→50 lines" test 의 정량화. Python `ast` 표준 모듈 + radon 패턴 자체 구현.

**파일**: `scripts/senior_engineer_metrics.py` (외부 의존성 0)

**5 가지 객관 metric**:
1. **LOC delta** — 변경 전후 line count
2. **Cyclomatic complexity** — McCabe (radon 등급 A~F)
3. **Unused symbols** — import / function 미사용
4. **Speculative features** — TODO/FIXME marker, single-use class
5. **Dead code** — return/raise 이후 코드

**통합 함수**: `senior_engineer_test_score(code, original_code=None)`
→ Verifier 의 10번째 차원 (`senior_engineer_test`) 점수에 직접 입력.

**예시 점수 매핑**:
- 깨끗한 코드 (max_complexity ≤ 5, unused 0) → score 5
- max_complexity > 30 → -2 점
- unused > 5 → -1 점
- dead code 존재 → -0.5 점

**Verifier 통합**:
```python
from senior_engineer_metrics import senior_engineer_test_score
result = senior_engineer_test_score(worker_output_code, original_code=baseline_code)
verifier_report["quality_rubric"]["senior_engineer_test"] = result
```
</integration_note>
